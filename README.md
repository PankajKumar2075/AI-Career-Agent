# AI Career & Placement Preparation Agent

An intelligent career preparation platform
using Machine Learning, Generative AI,
and Agentic AI.

## Main Modules

1. Resume Analysis
2. Career Recommendation
3. Skill Gap Analysis
4. Personalized Learning Roadmap
5. AI Mock Interview
6. Performance Tracking

## Technology Stack

- React.js
- Python
- FastAPI
- Scikit-learn
- Pandas
- NumPy
- Ollama
- LangGraph
- MongoDB
- ChromaDB
